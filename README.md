# Video Game Sales Analysis using SQL

## About the Project

This project is based on a video game sales dataset.

The main goal of this project was to use SQL to explore the data and find useful business insights related to game sales, revenue, platforms, genres, regions, and publishers.

I worked on this project to improve my SQL and data analysis skills.

## SQL Analysis

I used SQL to answer questions such as:

- Which platform has the highest total global revenue?
- Which genre has the highest total units sold?
- Which region generates the highest revenue?
- Which sales channel generates the highest revenue?
- Which 10 games have the highest global revenue?
- Which 10 games have the highest units sold?
- What is the average user score for each genre?
- Which publisher has the highest total revenue?
- Which Platform-Genre combination has the highest revenue?
- Which games have a high user score but low units sold?

## Advanced SQL

I also practiced advanced SQL concepts such as:

- RANK()
- PARTITION BY
- Window Functions
- Running Total
- LAG()
- GROUP BY
- HAVING
- Aggregate Functions
- Subqueries
- CTEs

For example, I used window functions to rank games within each platform and find the top games within each genre.
